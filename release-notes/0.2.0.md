First public build of Stacks: a sample manager for external drives and SD cards.

**Install:** download `Stacks-0.2.0-universal.dmg`, open it and drag Stacks to Applications. Signed and notarised; runs on Apple silicon and Intel Macs. From now on Stacks updates itself: it downloads new versions in the background and asks before restarting.

**What it does**
- Picks up SD cards and USB drives as they mount, and remembers them by volume, so samples survive a different mount point. Any drive can be excluded.
- Drop files, folders, zip packs or a download link to import.
- Reads key (with Camelot code) and BPM for every sample, folded into 70–140. Shows what mixes with the selected sample.
- Gapless loop preview in the library (L), so you can hear a bad seam before editing.
- Sample editor (E): trim, delete, silence, trim silence, fades, de-click, gain, normalise, reverse, undo/redo, zero-crossing and 1/16 snap.
- Auto loop finds the best 4, 2 or 1 bar loop; moved loop points apply as playback reaches them. Save the loop as its own file, beside the original or onto any drive.
- Rename with key and tempo at the end of the name (sort order never changes), copy to another drive, drag straight into a DAW.
